# vibe-control 0.3.5 便携安装与有界测试需求

## 目标

- 标准 Skill Installer 下载、仓库 `skill/` 子目录和普通目录复制均可完成开发包安装自检。
- 开发包安装完整性与正式包封印使用不同入口和无歧义结论。
- `test_package_release_audit.py` 与 `test_assurance_regressions.py` 具备叶级隔离、实时进度、超时和守恒计数，并在当前 Windows / Python 3.12 环境中各自于 240 秒内结束。

## 固定边界

- 版本为 `0.3.5`，Schema 保持 `3.2`。
- 包姿态保持 `DEVELOPMENT_DIAGNOSTIC`，`formalClaimsAllowed=false`，最高声明为 `DEVELOPMENT_CHECKED`。
- 便携副本只以重算后的 package/runtime manifest 与 assurance matrix 哈希建立内容身份，不声称 Git 来源证明。
- Git 根与 Git 子目录分别绑定当前仓库 commit/tree 或 subtree tree；子目录只检查 Skill 子树污染。
- 不创建 release/audit tag、GitHub Release、LICENSE 或正式封印。
- 不修改 Pulse、VibeCodingGovernance 或其他项目。

## 验收检查点

1. 无 Git 的标准下载副本通过安装自检，并可创建受开发声明上限约束的诊断控制面。
2. 安装自检报告开发包可用；正式封印校验器对同一开发包明确返回阻断，而非内容损坏。
3. 两个深度回归套件均输出完整、零失败、零 skip、零 timeout 的叶级计数，且各自在 240 秒内结束。

本文件与用户批准的《vibe-control 0.3.5 便携安装与有界测试修复》计划共同构成本任务需求事实源。
